# Screenshots

Three curated scenes, generated by listing tooling that is not part of this repository. They are
tracked on purpose: external directories that list Nostr apps want image URLs, and a link has to
keep working without anyone having run a build.

Every scene is synthetic — an invented article, invented commenters, and a throwaway key. Nothing
here is a real thread.
